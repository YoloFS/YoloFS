# Plan: Change inode number type from u64 to u32

## Problem
Inode numbers (`ino`) are currently `u64` throughout the codebase (kernel + CLI), but only 44 bits are ever used in the packed dirent format. The full 64-bit type is unnecessary and annoying to work with. Change to `u32`.

## Approach
Change all inode number types from `u64` to `u32` in both kernel module and CLI. The packed dirent value (`struct agfs_dstate`) remains a `u64` since it encodes multiple fields, but the ino field within it shrinks from 44 bits to 32 bits.

### New packed dirent inode layout
```
[63]    0        (tag)
[62:61] d_type   2 bits
[60]    in_base  1 bit
[59:48] reserved 12 bits (must be 0)
[47:16] ino      32 bits (was 44)
[15:0]  gen      16 bits
```

- Forward declarations: update `agfs_inode_path()`, `agfs_inode_alloc()`, `agfs_journal_add()`, `agfs_journal_modify()` params from `u64 ino` / `u64 *out_ino` → `u32` / `u32 *`
